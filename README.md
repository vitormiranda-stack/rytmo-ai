# RytmoAI

## Sobre

O RytmoAI é um aplicativo em desenvolvimento que tem como objetivo auxiliar na organização de rotinas com inteligência artificial. Entre as funcionalidades planejadas estão a importação de rotinas por PDF, o acompanhamento de tarefas e a integração com o Telegram.

## Tecnologias

- TypeScript
- Node.js
